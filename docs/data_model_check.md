# 데이터 확정과 모델 실행 확인 (Issue #2)

실제 상담 데이터의 구조·연결을 확인하는 독립 로더 초안과 합성 한국어 문장용 MiniLM CPU 실행 확인 도구다. 기존 검색·UI·공통 데이터 계약과 합성 샘플은 변경하지 않는다.

## 데이터 출처와 검토 범위

- **데이터명:** 민간 민원 상담 LLM 사전학습 및 Instruction Tuning 데이터
- **제공 플랫폼:** AI Hub
- **데이터셋 번호:** 71844
- **공식 출처:** [데이터 소개](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=71844&currMenu=115&topMenu=100)
- **검토 범위:** 해당 데이터셋 중 엘지유플러스 통신 상담 원천과 분류 라벨
- **선정 상태:** 프로젝트 사용 데이터셋으로 확정
- **출처 표기:** 과학기술정보통신부·한국지능정보사회진흥원 AI 학습용 데이터 구축 사업 결과물. 세부 구축 정보는 공식 소개 참조.

2026-11-02 승인받아 보유한 로컬 파일로 원천 상담 3,216건, 분류 16,080건을 확인했다. 분류 중 `상담 요건` 3,216건을 골라 단일 요건 2,658건·다수 요건 558건을 구분했다. 가공 질의응답 7,497건은 구조·연결만 확인했으며 검색 코퍼스로 사용하지 않았다. 원천과 연결되는 질의응답의 상담 수는 3,154건이다.

JSON 내부의 `source`와 `source_id` 조합으로 연결하며 파일명으로 연결하지 않는다. 확인한 원천-요건 연결의 누락·중복·유형 불일치는 0건이다. 업무 유형은 원래 표기 59종이며 공백 제거 시 56종이라는 값은 진단일 뿐 자동 병합하지 않는다.

아카이브는 TAR → 완전한 ZIP을 담은 `.zip.part0` → JSON 리스트 형태였다. 이번 파일은 각각 단독 ZIP으로 읽혔다. 다른 분할 파일의 완전성을 가정하거나 여러 part를 자동 연결하지 않는다. 디스크에 추출하지 않으며, 압축 TAR는 지원하지 않는다.

프로젝트 사용 데이터셋은 AI Hub의 「민간 민원 상담 LLM 사전학습 및 Instruction Tuning 데이터」 중 엘지유플러스 통신 상담 원천과 분류 라벨로 확정했다. 다른 후보를 섞거나 기존 합성 30건을 교체하지 않는다. 데이터셋 확정은 이용 허가 범위 확인과 별개다.

다운로드 승인은 확인했지만 팀원 열람·임베딩 검색·공개 데모 활용 허용까지 확인된 것은 아니다. [AI Hub 이용정책](https://aihub.or.kr/intrcn/guid/usagepolicy.do)과 개별 승인 조건을 확인해야 한다. 이용정책은 학습용 제한, 미승인 제3자 열람·제공 제한, 국외 반출 별도 합의 등을 명시한다. 실제 데이터와 그 식별자·문장·임베딩을 Git에 추가하지 않는다.

## 로더와 현재 검증 결과

- `src/data/aihub_loader.py`: 메모리 아카이브 읽기, 크기·수량·압축률 제한, 후보 추출·보류, 집계
- `src/data/aihub_schema.py`: 원천·분류 JSON 어댑터. 분류 중 `상담 요건`만 선별
- `tests/test_aihub_loader.py`, `tests/test_aihub_schema.py`: 상담 원본 대신 합성 입력으로 검사

저장소 루트에서 Python 3.10 이상으로 실행한다. 로더 테스트는 표준 라이브러리만 사용한다.

```console
python -m unittest discover -s tests -v
```

2026-11-02 합성 테스트 **40개 통과**. 정상·손상 TAR/ZIP, 완전/불완전 `.zip.part0`, 경로 이동 문자열, 링크, 잘못된 JSON·중복 키, 크기·수량·압축률 제한, 조인 누락·충돌, 발화 보류, 재실행 일치를 확인했다. 악성 입력 전체에 대한 보안 보증은 아니다.

로컬 원천에서는 유형별 빈도 내림차순·동률 문자순으로 정한 상위 8종과 단일 요건의 교집합 2,192건을 재현했다. 다음은 초기 보수적 규칙의 결과다.

| 다중 요청 가능성 보류 | 224 |

동일 입력의 두 번 실행에서 후보·순서·집계가 일치했다. **후보 수는 의미 정확도가 아니다.** 보류가 많은 초기 규칙으로, 유형별 후보와 보류 사례를 섞은 수작업 표본 검수 후 보완해야 한다. 정규식만으로 개인정보 부재를 보증하지 않는다.

실험용 유형 매핑은 기존 공통 코드와 별개다. 실데이터에 검수된 의미 중복 정답이 없어 `duplicate_group`, `split`, `data/questions.csv`를 생성하지 않는다. 검색·평가 담당과 계약을 합의한 뒤 통합한다.

## MiniLM CPU 실행 방법

모델: [`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2)

확인한 모델 revision: `e8f8c211226b894fcb81acc59f3b34ba3efd5f42`

Windows에서는 `scripts/download_and_check_minilm.cmd`를 실행한다. 저장소의 `.venv`에 CPU용 torch와 sentence-transformers를 설치하고 공개 모델을 다운로드한 뒤 합성 한국어 3문장만 검사한다. 이번에 실행한 패키지 버전은 아래 검증 결과에 기록했다. 팀 공통 requirements.txt의 버전 고정은 후속 통합 단계에서 진행한다. 설치·모델 다운로드에 네트워크와 디스크 공간이 필요하다. 유료 API를 사용하지 않는다.

이미 필요한 패키지와 모델이 설치되어 있다면 다음 명령으로 다운로드 없이 검사한다.

```console
python scripts/minilm_smoke.py --revision e8f8c211226b894fcb81acc59f3b34ba3efd5f42
```

명시적으로 모델 다운로드를 허용하려면 `--download`를 추가한다. 결과는 기본적으로 `scripts/reports/minilm_smoke.json`, 모델 캐시는 `scripts/.model_cache/`에 생성하며 Git에서 제외한다. 설치 도구가 성공하면 패키지 목록도 `scripts/reports/minilm_environment.txt`에 기록한다.

통과 조건은 `(3, 384)` 형태의 유한 수치 벡터와 보고서의 `status: passed`다. 모델 revision·패키지 버전·CPU 장치·입력 문자/토큰 길이·최대 길이·절단 여부·경과시간을 기록한다. 이 검사는 검색 성능 평가가 아니다.

**현재 상태:** 2026-11-03(KST) MiniLM CPU 로딩과 합성 한국어 3문장의 임베딩 생성을 확인했다. Windows 다운로드 도구 실행 후 `status: passed`를 확인했고, 추가 다운로드 없이 같은 모델을 다시 실행해 통과했다. 아래는 재검사 결과다.
